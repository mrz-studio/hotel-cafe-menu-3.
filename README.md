# منوی دیجیتال کافه هتل

این پروژه برای انتشار رایگان با GitHub Pages آماده شده است.

## انتشار در GitHub Pages

1. وارد حساب GitHub شوید و یک Repository جدید بسازید.
2. نام دلخواهی مثل `hotel-cafe-menu` انتخاب کنید.
3. فایل‌های داخل این پوشه (`index.html` و `.nojekyll`) را در ریشه Repository بارگذاری کنید.
4. وارد مسیر `Settings > Pages` شوید.
5. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
6. Branch را روی `main` و پوشه را روی `/ (root)` بگذارید و Save کنید.
7. پس از پایان انتشار، GitHub آدرس سایت را در همان صفحه نمایش می‌دهد؛ معمولاً شبیه این:
   `https://USERNAME.github.io/hotel-cafe-menu/`

## QR Code

پس از اینکه آدرس نهایی GitHub Pages فعال شد، همان URL را به QR Code تبدیل می‌کنیم.
تا وقتی آدرس نهایی مشخص نشده، QR نهایی نسازید.

## نکات فنی

- فایل اصلی صفحه با نام `index.html` قرار گرفته تا به‌عنوان صفحه ورودی GitHub Pages شناسایی شود.
- ظاهر، متن‌ها، محصولات، قیمت‌ها، تصاویر و ساختار صفحه عمداً تغییر داده نشده‌اند.
- تصاویر داخل HTML به‌صورت Base64 تعبیه شده‌اند؛ بنابراین برای تصاویر، فایل جداگانه‌ای لازم نیست.
- فونت‌ها از Google Fonts بارگیری می‌شوند؛ برای دریافت همان فونت‌ها اینترنت لازم است و در صورت در دسترس نبودن، فونت جایگزین مرورگر نمایش داده می‌شود.
- GitHub Pages میزبانی استاتیک است؛ این نسخه پنل مدیریت یا دیتابیس ندارد.

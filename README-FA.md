# پنل مدیریت منوی کافه هتل

این بسته نسخه آماده اتصال منوی فعلی به پنل مدیریت است. ظاهر اصلی صفحه منو دست‌نخورده مانده؛ فقط اسکریپت همگام‌سازی به آن اضافه شده است.

## قبل از انتشار
1. در https://supabase.com یک پروژه بساز.
2. در Authentication > Providers > Email، ورود ایمیلی را فعال و ثبت‌نام عمومی (Sign ups) را غیرفعال کن.
3. از Authentication > Users یک کاربر مدیر با ایمیل و رمز قوی بساز.
4. در SQL Editor محتوای `supabase-setup.sql` را اجرا کن.
5. از Project Settings > API مقدار Project URL و کلید publishable (یا anon قدیمی) را بردار و در `config.js` جایگزین `YOUR_...` کن. کلید `service_role` را هرگز در فایل‌های سایت قرار نده.
6. همه فایل‌های این پوشه را در ریشه مخزن GitHub Pages آپلود کن و تغییرات را Commit کن. فایل `index.html` باید جایگزین نسخه قبلی شود.
7. پنل در آدرس `https://USERNAME.github.io/hotel-cafe-menu/admin.html` باز می‌شود.
8. با کاربر مدیر وارد شو و فقط یک بار روی «وارد کردن منوی فعلی» بزن. این کار دسته‌بندی‌ها، محصولات و عکس‌های فعلی را وارد می‌کند.

## قابلیت‌های نسخه اول
- تغییر نام، عکس، ترتیب و وضعیت نمایش محصولات
- افزودن و حذف محصول
- ویرایش نام، توضیح و وضعیت نمایش دسته‌بندی‌های فعلی
- تغییر ساعت کاری، آدرس و شماره تماس
- نمایش تغییرات در منوی مشتری پس از تازه‌سازی صفحه

## نکات مهم امنیتی و فنی
- کلید publishable/anon برای مرورگر طراحی شده و مجوز نوشتن فقط به کاربر واردشده داده می‌شود. RLS در SQL فعال است.
- فقط حسابی را در Supabase بساز که مجاز به مدیریت منو باشد؛ ثبت‌نام عمومی را باز نگذار.
- تصاویر عمومی‌اند تا مشتری بدون ورود بتواند آن‌ها را ببیند.
- این نسخه هنوز امکان افزودن دسته‌بندی جدید و ویرایش لینک اینستاگرام/ایمیل را ندارد؛ می‌توان در مرحله بعد اضافه کرد.
- برای اولین واردسازی، فایل index.html باید در همان پوشه و روی سایت منتشر شده باشد. اگر واردسازی در میانه کار خطا داد، قبل از تکرار، وضعیت جدول‌ها و Storage را بررسی کن تا داده تکراری ساخته نشود.
